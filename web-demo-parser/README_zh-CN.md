# DDNet Demo 解析工具 - 使用说明

一个功能全面的网页工具，用于解析和分析 DDNet 游戏回放文件（`.demo` 文件）。

## 功能特点

- 📁 **多文件上传** - 支持一次性上传和解析多个 demo 文件
- 📊 **详细统计** - 显示每个 demo 文件的完整信息
- 🗺️ **地图信息** - 提取地图名称、大小、CRC 校验和 SHA256 哈希
- ⏱️ **时间数据** - 显示时长、tick 数和时间轴标记
- 🎨 **现代界面** - 美观的响应式设计
- ⚡ **纯前端** - 无需服务器，所有解析在浏览器中完成
- 🔒 **隐私保护** - 文件不会上传到任何服务器

## 使用方法

1. 用浏览器打开 `web-demo-parser/index.html`
2. 拖放 demo 文件到上传区域，或点击选择文件
3. 查看每个文件的详细统计信息
4. 可以一次性上传多个文件进行对比分析

## 解析的内容

### 基本信息
- Demo 文件版本
- 网络版本
- 录制类型
- 录制时间戳
- 总时长

### 地图信息
- 地图名称
- 地图大小
- CRC 校验码
- SHA256 哈希（版本 6+）

### 时间轴标记
- 标记数量
- 每个标记的 tick 位置
- 转换为时间戳显示

### 统计数据
- 总块数（chunks）
- Tick 标记数
- 关键帧数
- 快照数
- 增量快照数
- 消息数
- 起始和结束 tick

## Demo 文件格式

DDNet demo 文件采用二进制格式，包含：

1. **文件头**（176 字节）
   - 标识符："TWDEMO\0"
   - 版本号
   - 网络版本字符串
   - 地图名称
   - 地图大小和 CRC
   - Demo 类型
   - 时长和时间戳

2. **时间轴标记**（260 字节，版本 > 3）
   - 标记数量
   - 标记数组（最多 64 个）

3. **SHA256 扩展**（48 字节，版本 >= 6）
   - 扩展 UUID
   - 地图 SHA256 哈希

4. **地图数据**（可变大小）
   - 嵌入的地图文件

5. **数据块**（可变大小）
   - Tick 标记
   - 快照数据
   - 增量快照
   - 消息数据

## 浏览器要求

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

需要支持：ArrayBuffer、DataView、ES6 类、异步函数

## 技术细节

解析器实现了 DDNet demo 文件格式规范（参见 `src/engine/shared/demo.cpp`）：
- 大端序 32 位整数解析
- 以 null 结尾的 UTF-8 字符串
- 固定大小的文件头结构
- 基于块的可变长度数据
- 压缩的 tick 增量支持

## 局限性

- 不解压缩快照/消息数据（需要游戏特定的解码器）
- 不解析玩家名称或聊天记录（需要完整的状态解析）
- 不提取或显示地图文件数据
